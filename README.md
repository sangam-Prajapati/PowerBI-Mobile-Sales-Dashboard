# PowerBI-Mobile-Sales-Dashboard
Interactive Power BI dashboard for mobile sales analysis.


 📊 Mobile Sales Dashboard | Power BI

📌 Project Overview

This project is an interactive **Power BI Dashboard** developed to analyze mobile sales data. It helps businesses monitor sales performance, customer purchasing behavior, payment methods, and monthly trends using dynamic visualizations.

---

 🚀 Dashboard Features

- 📈 Total Sales KPI
- 🛒 Total Quantity Sold
- 💳 Total Transactions
- 📊 Average Sales Value
- 🗺️ Interactive Sales Map
- 📅 Monthly Sales Analysis
- 📱 Mobile Brand Performance
- 💰 Payment Method Distribution
- 📆 Sales by Day
- 🎯 Dynamic Filters (Month, Brand, Payment Method)
